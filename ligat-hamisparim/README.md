# ליגת המספרים ⚽

חידון כדורגלנים לילדים: חשבון עם מספרי חולצה (חיבור, חיסור, כפל, חילוק) וכתיב שמות שחקנים באנגלית, עם הקראה במבטא בריטי, לוח כפל מדבר, הסברים מוקלטים ואלבום מדבקות.

- `index.html` — עיצוב ומסכים
- `app.js` — לוגיקת המשחק
- `players.js` — מאגר השחקנים (668 שחקנים, 27 מועדונים, 24 נבחרות; מספרי חולצה לפי עונת 2025/26, ניתן לערוך)
- `build-artifact.sh` — בונה קובץ יחיד ב-`dist/`

עובד אופליין, שומר התקדמות במכשיר. מתאים לאייפד: לפתוח בספארי → שיתוף → "הוסף למסך הבית".
